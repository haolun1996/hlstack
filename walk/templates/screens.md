# Screen map — every screen, where its code lives, what it looks like

Look a screen up here before searching the codebase. Each row: the screen as a person sees
it → URL → code → screenshot → the walk run that last checked it. A screenshot is
`.hlstack/bugs/<Walked>/walkthrough/<area>/<file>`. An empty Walked cell means never checked.
Kept by the `walk` skill; the skeleton came from `/walk-setup` (routes), so a row without a
screenshot is a screen that exists but has not been walked.
